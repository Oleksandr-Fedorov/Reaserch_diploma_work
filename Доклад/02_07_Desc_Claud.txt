2. TOPIC (FIXED — DO NOT SUGGEST CHANGING)

Image manipulation detector with localization and explainability.

System takes an image, determines if it was manipulated (object insertion/splicing), and shows WHERE, not just a verdict.

Three planned components:


ELA module (Error Level Analysis) — hand-implemented algorithm, not ML. Detects JPEG recompression artifact inconsistencies.
CNN classifier — fine-tuned on ELA maps, classifies authentic/manipulated.

3. WHAT HAS BEEN DONE (chronological, all hands-on, all results real)

Step 1 — ELA implementation & manual exploration. Wrote ela.py. Tested on real CASIA1 image pairs. Found experimentally: ELA gives strong signal when object history-of-compression differs from background (e.g., black square pasted on face), weak/noisy signal when spliced object + background share similar recompression history, and no signal at all when the whole composite is uniformly resaved (bird-in-garden case — visually obvious splice, ELA showed uniform noise, no localization).

Step 2 — Dataset preparation. Batch script converts CASIA1 Au/Sp folders into REAL_/FAKE_ prefixed ELA maps. 1721 images generated.

4. THE CORE PROBLEM DISCOVERED (this is the current frontier)

Tested the deployed model on images outside its training distribution:


A manually-composited image (real head swapped onto a real cat body, saved as fresh JPEG) → classified REAL, high confidence. Recompression flattened the ELA signal (expected, matches Step 1 findings).
An image pulled directly from CASIA2 Tp folder (model was trained only on CASIA1) → classified AUTHENTIC, 95.99% confidence, despite being a known splice.


This is a generalization failure, not randomly bad luck. Two non-exclusive candidate explanations are on the table:

Hypothesis A — Data/generalization problem: Model overfit to CASIA1-specific characteristics (camera sources, JPEG quality distribution, splice style), not to "manipulation" as a general concept. Fixable by training on more diverse data + augmentation.

Hypothesis B — Feature-sufficiency problem: ELA alone is fundamentally blind to certain manipulation types (heavy recompression, well-blended/feathered edges, color-matched splices) regardless of how much data or which architecture processes it. No amount of training recovers information that isn't in the input.

Current belief (not yet proven): likely a mix, with data/generalization being the larger share but ELA's ceiling being real. This has NOT been rigorously tested yet — see Section 6, Step 0.

Round 1 advice (mine, an AI assistant): proposed jumping to a two-branch fusion architecture (separate ResNet18 per signal: ELA branch + Noise-residual branch, concatenate features before final FC), citing forensics literature precedent (RGB-N style late fusion is more standard than early-channel-stacking, per papers like Zhou et al. RGB-N).

Round 2 advice (a different AI, more skeptical): pushed back hard — argued architecture changes are premature until it's proven whether the bottleneck is (a) insufficient/narrow training data or (b) fundamental insufficiency of the ELA feature itself. Proposed:


Don't build dual-stream yet. Test multi-channel stacking (RGB+ELA+Noise+SRM as extra input channels into a single ResNet, modifying conv1 to accept N channels) as a cheaper first architectural step.
Before any architecture change: run diagnostic/ablation experiments — (1) recompression-robustness test: same fake image saved at JPEG q=95→60, run through the model, check if confidence swings wildly (would indicate the model is reading JPEG-specific noise rather than manipulation semantics); (2) error breakdown by manipulation type (crude paste / feathered / color-matched / copy-move) on existing test data — no new training required for either.
If pursuing more datasets: CASIA2 + Columbia + IMD2020 preferred; flagged that Coverage is a copy-move dataset (different artifact signature than splicing) and shouldn't be casually mixed in without caveats; cautioned against collecting 5-6 datasets at once as scope creep.
Also proposed multi-task learning (classification + coarse localization) as a later-stage idea, contingent on some datasets having ground-truth masks.
